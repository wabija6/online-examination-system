## 📖 About The Project

The Online Examination System is a secure, role-based application that allows educational institutions to conduct exams digitally. It eliminates the need for paper-based testing, provides instant grading, and offers deep analytics for teachers and administrators.

### ✨ Key Features

**👑 Admin Panel:**
*   **User Management:** Full control to add, view, and delete Students, Teachers, and Admins.
*   **System Oversight:** Monitor all exams, questions, and results across the entire system.
*   **Analytics & Reports:** View system-wide statistics and download CSV reports.

**👨‍🏫 Teacher Panel:**
*   **Exam Creation:** Create exams with specific titles, subjects, durations, and active timeframes.
*   **Question Bank:** Add Multiple Choice Questions (MCQs) with 4 options, correct answers, marks, and explanations.
*   **Results & Analytics:** Track student performance, view average scores, and see pass/fail rates per exam.

**👨‍🎓 Student Panel:**
*   **Take Exams:** Clean, distraction-free exam interface with a real-time countdown timer.
*   **Question Navigator:** Easily jump between questions and see which ones are answered.
*   **Instant Results:** Get immediate scoring and pass/fail feedback upon submission.
*   **Profile & History:** View personal academic performance and past exam history.

## 🛠️ Technology Stack

*   **Frontend:** HTML5, CSS3, JavaScript, Bootstrap 5, Chart.js
*   **Backend:** PHP (Native)
*   **Database:** MySQL
*   **Development Environment:** XAMPP, VS Code
